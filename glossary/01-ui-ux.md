# UI/UX · 화면과 컴포넌트

> [전체 목차](../README.md) · [알파벳 색인](../INDEX.md) · [참고 자료](../REFERENCES.md)

이 문서의 용어는 이해하기 쉬운 요약 정의입니다. 구체적인 동작은 공식 명세·디자인 시스템에 따라 달라질 수 있습니다.

| 용어 | 설명 | 예시·활용 |
| --- | --- | --- |
| **Header** | 페이지나 섹션 상단의 머리말 영역. | 사이트 로고·내비게이션 배치 |
| **Footer** | 페이지 하단의 보조 정보 영역. | 약관·저작권·연락처 |
| **Navbar** | 페이지/서비스 주요 경로를 보여 주는 내비게이션 바. | 상단 메뉴 |
| **GNB** | 서비스 전역에서 공통으로 쓰는 Global Navigation Bar. | 제품·고객센터 탭 |
| **LNB** | 특정 영역의 하위 메뉴를 제공하는 Local Navigation Bar. | 설정 세부 메뉴 |
| **Hero** | 첫 화면에서 핵심 메시지와 이미지를 강조하는 큰 영역. | 랜딩 페이지 첫 섹션 |
| **CTA** | 사용자의 다음 행동을 유도하는 Call to Action. | 가입하기 버튼 |
| **Above the Fold** | 스크롤 전 처음 보이는 화면 범위. | 첫 화면 핵심 가치 노출 |
| **Landing Page** | 유입자가 특정 행동을 하도록 설계한 목적 페이지. | 캠페인 페이지 |
| **Sidebar** | 콘텐츠 옆에 놓이는 보조 탐색/정보 영역. | 문서 목차 |
| **Breadcrumb** | 현재 페이지의 상위 계층을 보여 주는 경로 탐색. | 홈 > 설정 > 계정 |
| **Tab** | 동일 맥락의 콘텐츠 뷰를 전환하는 선택 항목. | 전체·완료·진행 중 |
| **Tab Bar** | 여러 탭을 묶어 이동하게 하는 막대. | 모바일 하단 탭 |
| **Bottom Navigation** | 주요 목적지를 화면 아래에서 이동하는 내비게이션. | 모바일 앱 하단 메뉴 |
| **Drawer** | 화면 측면에서 밀려 나오는 패널. | 모바일 메뉴 |
| **Bottom Sheet** | 화면 아래에서 올라오는 작업·선택 패널. | 공유 옵션 |
| **Side Sheet** | 화면 측면에 펼쳐지는 작업 패널. | 상세 정보 편집 |
| **Modal** | 기존 화면 위에 올라와 진행 흐름에 개입하는 UI. | 확인 창·로그인 |
| **Dialog** | 사용자에게 정보·결정·입력을 요구하는 대화 상자. | 삭제 확인 |
| **Popover** | 기준 요소 근처에 나타나는 작은 부가 UI. | 필터 옵션 |
| **Tooltip** | 가리키기·포커스 시 짧게 나타나는 설명. | 아이콘 의미 안내 |
| **Toggletip** | 사용자가 명시적으로 열고 닫을 수 있는 설명 UI. | 도움말 버튼 |
| **Toast** | 작업 결과를 잠깐 알리고 사라지는 비차단 알림. | 저장 완료 |
| **Snackbar** | 화면 가장자리의 간단한 피드백 표시; 디자인 시스템에 따라 Toast와 유사. | 실행 취소 안내 |
| **Alert** | 중요한 상태나 위험을 알려 주는 메시지. | 권한 오류 안내 |
| **Banner** | 페이지 안에서 넓게 노출되는 공지·상태 영역. | 서비스 점검 공지 |
| **Badge** | 개수·상태 등을 작게 강조하는 표식. | 알림 3 |
| **Chip** | 값·필터·선택을 간결하게 표현하는 작은 요소. | 선택한 태그 |
| **Card** | 하나의 항목 정보를 묶는 사각형 컨테이너. | 상품 카드 |
| **Avatar** | 사용자나 대상의 프로필을 나타내는 이미지·이니셜. | 작성자 아이콘 |
| **Accordion** | 섹션을 펼치고 접는 UI 패턴. | FAQ |
| **Carousel** | 여러 콘텐츠를 한 영역에서 순차 노출. | 이미지 슬라이드 |
| **Stepper** | 단계별 진행 상황 또는 단계 이동 UI. | 가입 1/3 |
| **Pagination** | 콘텐츠 목록을 페이지 단위로 나누는 탐색. | 이전·다음 |
| **Infinite Scroll** | 스크롤을 내릴수록 항목을 추가로 로딩하는 패턴. | 피드 |
| **Skeleton** | 실제 콘텐츠 구조를 닮은 로딩 자리 표시 UI. | 카드 뼈대 |
| **Spinner** | 작업 진행 중임을 반복 동작으로 알리는 표시. | 로딩 원 |
| **Progress Bar** | 진행률을 연속적인 막대로 표현. | 파일 업로드 70% |
| **Empty State** | 표시할 데이터가 없을 때 안내·행동을 제시하는 화면. | 검색 결과 없음 |
| **Error State** | 오류 발생 시 원인·복구 행동을 알려 주는 화면. | 재시도 버튼 |
| **Form** | 사용자 입력 요소를 한 작업으로 묶는 구조. | 회원가입 폼 |
| **Input** | 한 줄 값 입력 필드. | 이메일 |
| **Textarea** | 여러 줄 텍스트 입력 영역. | 의견 작성 |
| **Select** | 선택 목록에서 하나의 값을 고르는 입력. | 국가 선택 |
| **Combobox** | 입력과 옵션 목록 선택을 결합한 요소. | 검색 가능한 도시 선택 |
| **Autocomplete** | 입력 중 적합한 후보를 제시. | 주소 검색 |
| **Checkbox** | 복수 선택·참/거짓 입력. | 약관 동의 |
| **Radio Button** | 그룹에서 하나만 고르는 입력. | 배송 방식 |
| **Switch** | 즉시 켜고 끄는 설정을 표현. | 알림 활성화 |
| **Slider** | 연속적인 수치 범위를 조정. | 음량 |
| **Date Picker** | 날짜를 고르는 입력. | 예약일 |
| **FAB** | 주요 행동을 위한 Floating Action Button. | 글쓰기 + 버튼 |
| **Wireframe** | 콘텐츠·배치 중심의 저충실도 설계안. | 회색 화면 초안 |
| **Mockup** | 색·이미지·스타일을 입힌 정적 화면 시안. | 완성 형태 목업 |
| **Prototype** | 상호작용 흐름을 시험하는 시제품. | 클릭 가능한 피그마 |
| **User Flow** | 목적 수행 과정의 화면·행동 경로. | 가입에서 결제까지 |
| **Affordance** | 요소가 어떤 행동을 허용하는지 암시하는 특성. | 눌러 보이는 버튼 |
| **Signifier** | 가능한 행동을 알아차리게 하는 시각·언어 신호. | 밑줄 링크 |
| **Visual Hierarchy** | 정보 중요도에 따라 시선을 유도하는 우선순위. | 큰 제목·강조 버튼 |
| **Progressive Disclosure** | 복잡성을 줄이기 위해 정보를 단계적으로 공개. | 고급 설정 펼치기 |
| **Onboarding** | 처음 사용자에게 제품 사용을 안내하는 과정. | 첫 실행 가이드 |
| **Microcopy** | 버튼·오류·힌트 등에 쓰이는 짧은 UI 문구. | 비밀번호를 입력하세요 |
