# 인터랙션 · 행동과 반응

> [전체 목차](../README.md) · [알파벳 색인](../INDEX.md) · [참고 자료](../REFERENCES.md)

이 문서의 용어는 이해하기 쉬운 요약 정의입니다. 구체적인 동작은 공식 명세·디자인 시스템에 따라 달라질 수 있습니다.

| 용어 | 설명 | 예시·활용 |
| --- | --- | --- |
| **Click** | 포인터 버튼 활성화 이벤트. | 마우스 클릭 |
| **Tap** | 터치 표면을 짧게 눌러 활성화하는 제스처. | 모바일 버튼 |
| **Double Click** | 짧은 시간 간격으로 두 번 클릭하는 동작. | 파일 열기 |
| **Long Press** | 길게 눌러 보조 행동을 여는 제스처. | 컨텍스트 메뉴 |
| **Hover** | 포인터가 요소 위에 놓인 상태. | 메뉴 강조 |
| **Focus** | 키보드 등 입력을 받을 대상으로 지정된 상태. | 입력 필드 포커스 |
| **Focus Visible** | 키보드 등의 맥락에서 포커스 표시가 필요하다고 판단되는 상태. | :focus-visible |
| **Active State** | 활성화되는 순간 또는 현재 활성 항목을 표현; CSS :active와 구별 필요. | 버튼 누르는 동안 |
| **Disabled State** | 요소를 사용할 수 없도록 설정한 상태. | 제출 조건 미충족 |
| **Readonly State** | 값을 편집할 수는 없지만 읽거나 포커스할 수 있는 입력 상태. | 읽기 전용 필드 |
| **Selected State** | 옵션·탭 등이 선택된 상태. | 현재 선택 탭 |
| **Swipe** | 한 방향으로 손가락을 쓸어 동작시키는 제스처. | 카드 넘기기 |
| **Drag and Drop** | 대상을 붙잡아 다른 위치에 놓는 조작. | 파일 업로드 |
| **Pointer Event** | 마우스·펜·터치 입력을 통합한 이벤트 모델. | pointerdown |
| **Touch Event** | 터치 접촉 정보에 대한 이벤트. | touchstart |
| **Keyboard Event** | 키 누름·뗌을 전달하는 이벤트. | keydown |
| **Event Bubbling** | 하위 요소에서 발생한 이벤트가 상위 요소로 전파. | 버튼 클릭이 카드로 전달 |
| **Event Capturing** | 이벤트가 상위부터 대상까지 내려가는 전파 단계. | capture listener |
| **Event Delegation** | 상위 요소 한 곳에서 하위 요소 이벤트를 처리하는 패턴. | 목록 클릭 처리 |
| **Prevent Default** | 이벤트의 브라우저 기본 동작을 취소. | 폼 제출 방지 |
| **Stop Propagation** | 이벤트의 이후 전파를 막는 동작. | 부모 클릭 핸들러 방지 |
| **Debounce** | 마지막 이벤트 이후 지정된 조용한 시간이 지난 뒤 실행하는 제어. | 검색 입력 300ms |
| **Throttle** | 일정 시간 동안 실행 빈도를 제한하는 제어. | 스크롤 핸들러 |
| **Leading Edge** | 이벤트 묶음이 시작할 때 즉시 실행하는 옵션. | 첫 클릭 즉시 반응 |
| **Trailing Edge** | 이벤트 묶음의 끝에서 마지막 입력을 반영하는 옵션. | 마지막 입력 검색 |
| **Cooldown** | 수행 후 일정 시간 동안 같은 동작을 제한하는 정책. | 재전송 버튼 30초 |
| **Double-submit Guard** | 처리 중 중복 제출을 막는 UI/애플리케이션 보호. | 결제 중 버튼 비활성 |
| **Transition** | 상태 변경 사이의 스타일 값을 시간에 걸쳐 보간. | hover 배경 전환 |
| **Animation** | 정해진 시간 흐름에 따라 속성을 변화시키는 표현. | 진입 애니메이션 |
| **Keyframe** | 애니메이션의 특정 시점별 스타일 선언. | @keyframes |
| **Easing** | 애니메이션 시간에 따른 변화 속도 함수. | ease-in-out |
| **Spring Animation** | 탄성·감쇠를 모델링한 움직임. | 카드 복귀 모션 |
| **Transform** | 요소의 이동·회전·확대 등 시각 변형. | translateX |
| **Fade** | 투명도 변화를 이용한 등장·퇴장. | 모달 fade-in |
| **Slide** | 위치 이동을 이용한 등장·퇴장. | 바텀시트 올리기 |
| **Microinteraction** | 작은 행동에 대한 짧고 직접적인 피드백. | 좋아요 하트 반응 |
| **Reduced Motion** | 움직임 민감 사용자 설정에 맞춰 애니메이션을 줄이는 대응. | prefers-reduced-motion |
| **Scroll Snap** | 스크롤 종료 위치를 지정 지점에 맞춰 정렬. | 가로 카드 스냅 |
| **Scroll Lock** | 특정 UI가 열렸을 때 배경 스크롤을 제한. | 모달 오픈 |
| **Focus Trap** | 모달 등 내부에서 포커스 이동을 가두는 패턴. | Tab 키 순환 |
| **Outside Click** | 팝오버 외부 입력을 감지하여 닫는 패턴. | 메뉴 닫기 |
| **Optimistic Feedback** | 서버 확인 전 사용자 행동을 즉시 화면에 반영. | 좋아요 즉시 표시 |
| **Haptic Feedback** | 진동 등 촉각으로 행동 결과를 알리는 피드백. | 모바일 버튼 진동 |
| **Gesture Conflict** | 복수 제스처 인식 규칙이 충돌하는 상황. | 가로 스와이프와 세로 스크롤 |
| **Touch Target** | 사용자가 터치하기 위한 상호작용 영역. | 작은 아이콘의 터치 영역 |
